First-time account connection

Instagram requires account-owner authorization. This one-time step needs a professional (Creator or Business) account and a Meta developer app.

  1. Open Meta app setup and choose Instagram API setup with Instagram Login.
  2. Add the test account, accept any tester invitation, and generate its access token with instagram_business_basic.
  3. Paste that token below once. It stays in an ignored local file on this computer.
After connecting, future test runs only need the handle. Each different account must be authorized separately.
